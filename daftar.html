Kod sekolah anda
  1. Buat salinan sistem. Log masuk dengan akaun sekolah, klik butang Buat salinan sistem di bawah, kemudian Make a copy.
  2. Terbitkan sebagai web app. Dalam salinan itu, buka Extensions › Apps Script, klik Deploy › New deployment › Web app. Tetapkan Execute as: Me dan Who has access: Anyone within domain sekolah. Klik Deploy, kemudian Authorize access dan tandakan semua kotak kebenaran (Select all) (jika ada amaran: Advanced › Go to … (unsafe) › Allow). Salin URL web app.
  3. Aktifkan. Buka URL web app. Anda menjadi ADMIN secara automatik. Masukkan kod sekolah di atas pada skrin Aktifkan Sistem.
  4. Mula guna. Buang data contoh (menu Sistem Agihan Tugas › Buang data contoh dalam Sheet), lengkapkan Tetapan › Sekolah, dan import senarai guru.
